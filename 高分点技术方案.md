## 一、复杂数据统计接口设计

### 1.1 设计目标
实现多维度、高性能的数据统计功能，支撑前端数据看板可视化展示。

### 1.2 技术选型

- **异步处理**: @Async（适用于耗时统计）

### 1.3 核心统计接口设计

#### 1.3.1 学生成绩统计
```java
// 接口路径: /api/statistics/getStudentScoreStatistics
// 功能: 按学期、学院、专业多维度统计成绩
@Query(value = "SELECT " +
    "c.name as courseName, " +
    "AVG(cs.score) as avgScore, " +
    "MAX(cs.score) as maxScore, " +
    "MIN(cs.score) as minScore, " +
    "COUNT(cs.selectionId) as studentCount " +
    "FROM course_selection cs " +
    "JOIN course c ON cs.courseId = c.courseId " +
    "JOIN student s ON cs.studentId = s.personId " +
    "WHERE c.semester = :semester " +
    "GROUP BY c.courseId, c.name " +
    "ORDER BY avgScore DESC", nativeQuery = true)
List<Object[]> getCourseScoreStatistics(@Param("semester") String semester);
```

## 二、WebSocket实时消息技术方案

### 2.1 技术选型
- **协议**: WebSocket (JSR 356)
- **框架**: Spring WebSocket + STOMP
- **消息代理**: 内置SimpleBroker（轻量级）或 RabbitMQ（生产级）
- **前端**: JavaFX WebView 或第三方库

### 2.2 架构设计

```

│             │ WebSocket│              │  JPA    │             │
```

### 2.3 核心实现

#### 2.3.1 WebSocket配置
```java
@Configuration
@EnableWebSocketMessageBroker
public class WebSocketConfig implements WebSocketMessageBrokerConfigurer {
    
    @Override
    public void configureMessageBroker(MessageBrokerRegistry config) {
        // 启用简单消息代理，用于向客户端推送消息
        config.enableSimpleBroker("/topic", "/queue");
        // 客户端发送消息的前缀
        config.setApplicationDestinationPrefixes("/app");
        // 用户专属消息前缀
        config.setUserDestinationPrefix("/user");
    }
    
    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        // 注册WebSocket端点，支持SockJS降级
        registry.addEndpoint("/ws")
                .setAllowedOriginPatterns("*")
                .withSockJS();
    }
}
```

#### 2.3.2 消息实体类
```java
@Entity
@Table(name = "system_message")
public class SystemMessage {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer messageId;
    
    private Integer senderId;      // 发送者ID
    private Integer receiverId;    // 接收者ID
    private String title;          // 消息标题
    private String content;        // 消息内容
    private String messageType;    // 消息类型：通知、审批、提醒
    private Boolean isRead;        // 是否已读
    private LocalDateTime sendTime;
    
    @PrePersist
    protected void onCreate() {
        sendTime = LocalDateTime.now();
        isRead = false;
    }
}
```

#### 2.3.3 消息服务层
```java
@Service
public class MessageService {
    
    @Autowired
    private SimpMessagingTemplate messagingTemplate;
    
    @Autowired
    private MessageRepository messageRepository;
    
    /**
     * 发送实时消息
     */
    public void sendMessage(Integer receiverId, String title, String content, String type) {
        // 1. 保存到数据库
        SystemMessage message = new SystemMessage();
        message.setReceiverId(receiverId);
        message.setTitle(title);
        message.setContent(content);
        message.setMessageType(type);
        messageRepository.save(message);
        
        // 2. 推送实时消息
        Map<String, Object> payload = new HashMap<>();
        payload.put("messageId", message.getMessageId());
        payload.put("title", title);
        payload.put("content", content);
        payload.put("type", type);
        payload.put("sendTime", message.getSendTime());
        
        // 向特定用户推送
        messagingTemplate.convertAndSendToUser(
            String.valueOf(receiverId), 
            "/queue/notifications", 
            payload
        );
    }
    
    /**
     * 广播消息（如系统公告）
     */
    public void broadcastMessage(String title, String content) {
        Map<String, Object> payload = new HashMap<>();
        payload.put("title", title);
        payload.put("content", content);
        payload.put("sendTime", LocalDateTime.now());
        
        messagingTemplate.convertAndSend("/topic/announcements", payload);
    }
}
```

#### 2.3.4  Controller 层
```java
@RestController
@RequestMapping("/api/message")
public class MessageController {
    
    @Autowired
    private MessageService messageService;
    
    /**
     * 获取未读消息数量
     */
    @PostMapping("/getUnreadCount")
    public DataResponse getUnreadCount(@RequestBody DataRequest dataRequest) {
        Integer userId = dataRequest.getInteger("userId");
        long count = messageService.countUnreadMessages(userId);
        return CommonMethod.getReturnData(Map.of("count", count));
    }
    
    /**
     * 获取消息列表
     */
    @PostMapping("/getMessageList")
    public DataResponse getMessageList(@RequestBody DataRequest dataRequest) {
        Integer userId = dataRequest.getInteger("userId");
        String type = dataRequest.getString("type");
        List<SystemMessage> messages = messageService.getMessages(userId, type);
        return CommonMethod.getReturnData(messages);
    }
    
    /**
     * 标记消息已读
     */
    @PostMapping("/markAsRead")
    public DataResponse markAsRead(@RequestBody DataRequest dataRequest) {
        Integer messageId = dataRequest.getInteger("messageId");
        messageService.markAsRead(messageId);
        return CommonMethod.getReturnMessageOK();
    }
}
```

```java
WebView webView = new WebView();

    public void showMessage(String title, String content) {
        Platform.runLater(() -> {

    }
```

### 2.6 性能与安全

#### 2.6.1 连接管理
- 限制单用户最大连接数
- 实现心跳检测（Ping/Pong）
- 断线重连机制

#### 2.6.2 消息持久化
- 所有消息先入库再推送
- 离线消息缓存（用户上线后推送）
- 定期清理历史消息（如30天前）

#### 2.6.3 安全控制
- WebSocket 连接需携带 JWT Token
- 消息发送权限校验
- 防止消息轰炸（频率限制）

```java
// WebSocket 握手拦截器
public class JwtHandshakeInterceptor implements HandshakeInterceptor {
    
    @Override
    public boolean beforeHandshake(ServerHttpRequest request, 
                                   ServerHttpResponse response,
                                   WebSocketHandler wsHandler,
                                   Map<String, Object> attributes) {
        // 从 URL 参数或 Header 获取 Token
        String token = extractToken(request);
        if (!JwtUtil.validateToken(token)) {
            return false; // 拒绝连接
        }
        attributes.put("userId", JwtUtil.getUserId(token));
        return true;
    }
}
```
