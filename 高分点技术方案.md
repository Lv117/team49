```java
                                    // 竞赛:{"competitionName":"ACM","award":"一等奖"}
                                    // 成果:{"patentType":"发明专利","status":"已授权"}
```

**类型路由设计**:
```java
@Service
public class DevelopmentService {
    
    public DataResponse saveDevelopment(DataRequest dataRequest) {
        String type = dataRequest.getString("developmentType");
        
        // 根据类型进行不同的业务校验
        switch (type) {
            case "honor":
                return saveHonor(dataRequest);
            case "innovation":
                return saveInnovation(dataRequest);
            case "competition":
                return saveCompetition(dataRequest);
            case "achievement":
                return saveAchievement(dataRequest);
            default:
                return CommonMethod.getReturnMessage("不支持的类型");
        }
    }
    }
}
```

### 1.3 综合绩分计算

#### 1.3.1 设计目标
实现可配置的综合绩分计算系统,支持管理员自定义权重,自动计算学生综合得分并排名。

#### 1.3.2 技术方案
```java
@Service
public class ComprehensiveScoreService {
    
    // 默认权重配置
    private static final Map<String, Double> DEFAULT_WEIGHTS = Map.of(
        "score", 0.4,        // 成绩40%
        "attendance", 0.2,   // 考勤20%
        "development", 0.2,  // 实践荣誉20%
        "consumption", 0.2   // 消费行为20%
    );
    
    /**
     * 计算学生综合绩分
     */
    public Double calculateStudentScore(Integer studentId) {
        // 1. 计算成绩得分(归一化到0-100)
        Double scoreScore = calculateScorePart(studentId);
        
        // 2. 计算考勤得分(出勤率)
        Double attendanceScore = calculateAttendanceScore(studentId);
        
        // 3. 计算实践荣誉得分(通过审批的项目数量)
        Double developmentScore = calculateDevelopmentScore(studentId);
        
        // 4. 计算消费行为得分(合理消费奖励)
        Double consumptionScore = calculateConsumptionScore(studentId);
        
        // 5. 加权求和
        return scoreScore * 0.4 + 
               attendanceScore * 0.2 + 
               developmentScore * 0.2 + 
               consumptionScore * 0.2;
    }
}
```

```java
// 接口路径: /api/statistics/getStudentScoreStatistics
// 功能: 按学期、学院、专业多维度统计成绩
@Query(value = "SELECT " +
    "c.name as courseName, " +
    "AVG(cs.score) as avgScore, " +
    "MAX(cs.score) as maxScore, " +
    "MIN(cs.score) as minScore, " +
    "COUNT(cs.selectionId) as studentCount " +
    "FROM course_selection cs " +
    "JOIN course c ON cs.courseId = c.courseId " +
    "JOIN student s ON cs.studentId = s.personId " +
    "WHERE c.semester = :semester " +
    "GROUP BY c.courseId, c.name " +
    "ORDER BY avgScore DESC", nativeQuery = true)
List<Object[]> getCourseScoreStatistics(@Param("semester") String semester);
```

**考勤趋势统计**:
```java
// 接口路径: /api/statistics/getAttendanceTrend
// 功能: 按月统计考勤趋势(折线图数据)
@Query(value = "SELECT " +
    "DATE_FORMAT(attendanceDate, '%Y-%m') as month, " +
    "SUM(CASE WHEN status = '出勤' THEN 1 ELSE 0 END) as presentCount, " +
    "SUM(CASE WHEN status = '缺勤' THEN 1 ELSE 0 END) as absentCount, " +
    "SUM(CASE WHEN status = '迟到' THEN 1 ELSE 0 END) as lateCount " +
    "FROM attendance " +
    "WHERE courseId = :courseId " +
    "AND attendanceDate BETWEEN :startDate AND :endDate " +
    "GROUP BY DATE_FORMAT(attendanceDate, '%Y-%m') " +
```

### 2.2 WebSocket实时消息技术方案

#### 2.2.1 技术选型
- **协议**: WebSocket (JSR 356)
- **框架**: Spring WebSocket + STOMP
- **消息代理**: 内置SimpleBroker(轻量级)
- **前端**: JavaFX WebView嵌入HTML5 WebSocket

#### 2.2.2 核心实现

**WebSocket配置**:
```java
@Configuration
@EnableWebSocketMessageBroker
public class WebSocketConfig implements WebSocketMessageBrokerConfigurer {
    
    @Override
    public void configureMessageBroker(MessageBrokerRegistry config) {
        config.enableSimpleBroker("/topic", "/queue");
        config.setApplicationDestinationPrefixes("/app");
        config.setUserDestinationPrefix("/user");
    }
    
    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        registry.addEndpoint("/ws")
                .setAllowedOriginPatterns("*")
                .withSockJS();
    }
}
```

**消息服务层**:
```java
@Service
public class MessageService {
    
    @Autowired
    private SimpMessagingTemplate messagingTemplate;
    
    /**
     * 发送实时消息
     */
    public void sendMessage(Integer receiverId, String title, String content, String type) {
        // 1. 保存到数据库
        SystemMessage message = new SystemMessage();
        message.setReceiverId(receiverId);
        message.setTitle(title);
        message.setContent(content);
        message.setMessageType(type);
        messageRepository.save(message);
        
        // 2. 推送实时消息
        Map<String, Object> payload = new HashMap<>();
        payload.put("messageId", message.getMessageId());
        payload.put("title", title);
        payload.put("content", content);
        payload.put("type", type);
        payload.put("sendTime", message.getSendTime());
        
        messagingTemplate.convertAndSendToUser(
            String.valueOf(receiverId), 
            "/queue/notifications", 
            payload
        );
    }
}
```

**应用场景**:
- 审批通知:项目/荣誉审批通过/驳回时通知学生
- 作业提醒:作业截止前提醒、教师批改完成通知
- 系统公告:管理员发布系统通知
